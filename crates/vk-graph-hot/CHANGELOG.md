# Changelog

All notable changes to this crate will be documented in this file.

This crate is versioned independently from `vk-graph`.

## [Unreleased]

## [0.2.0]

- Requires `vk-graph` `0.15.1` or later in the `0.15` series and Rust 1.95 or newer.
  The public API uses `vk-graph` types and is not compatible with `vk-graph` `0.14`.
- Updates the examples to `vk-graph-window` `0.2`. Libraries using shader hot reload
  no longer pull in the window helper.

## [0.1.1] - 2026-06-18

- Supports `vk-graph` `0.14.2`.

## [0.1.0] - 2026-05-30

- Initial release.
- Supports `vk-graph` `0.14`.
